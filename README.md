##  Kiến Trúc Hệ Thống (The 5-Layer Power Architecture)

Dự án tuân thủ nghiêm ngặt kiến trúc **Professional Layering**, đảm bảo tính bền vững và khả năng mở rộng không giới hạn:

### 1. Data Providers (Hạ Tầng)
Tầng kết nối mạnh mẽ với hệ sinh thái Cloud và Local.
- **Supabase:** Quản lý cơ sở dữ liệu thời gian thực và xác thực người dùng.
- **Hive:** Hệ thống lưu trữ Local siêu tốc cho các bản thảo vẽ tay phức tạp.
- **dotenv:** Bảo mật các API Key và cấu hình môi trường.

### 2. Repositories (Dữ Liệu)
Trung tâm quản lý logic dữ liệu thông minh.
- Đóng gói (Mapping) dữ liệu từ JSON sang Models.
- Xử lý cơ chế Caching thông minh để ứng dụng hoạt động mượt mà ngay cả khi offline.

### 3. Controllers (GetX - Bộ Não)
Điều phối toàn bộ trạng thái và logic nghiệp vụ.
- **LayoutController:** Quản lý Theme, màu sắc động và trạng thái giao diện toàn cầu.
- **ProfileController:** Quản lý danh tính nghệ sĩ và hệ thống trang bị (Persona Gear).
- **HomeController/CommunityController:** Quản lý tài nguyên và tương tác cộng đồng.

### 4. Bindings (Cấu Trúc Kết Nối)
Cơ chế Dependency Injection tự động, tối ưu hóa bộ nhớ và kiểm soát vòng đời của tất cả các dịch vụ.

### 5. Views & Widgets (Giao Diện)
Giao diện người dùng tinh xảo với các công nghệ hiển thị tiên tiến nhất:
- **Glassmorphism:** Hiệu ứng kính mờ chiều sâu trên các bảng điều khiển.
- **Fluid Animation:** Chuyển động cinematic từ thư viện `flutter_animate`.
- **Editorial Typography:** Sử dụng Google Fonts (Cinzel, Plus Jakarta Sans) để tạo phong cách tạp chí cao cấp.

### 🎨 Creative Hub (Marketplace)

## ⚙️ Quy Trình Cài Đặt & Phát Triển

Dành cho các nhà phát triển và nghệ sĩ muốn đóng góp cho ArtVerse:

1. **Chuẩn Bị:**
   - Cài đặt **Flutter SDK 3.29.0** hoặc mới hơn.
   - Cấu hình file `.env` với các khóa `SUPABASE_URL` và `SUPABASE_ANON_KEY`.

2. **Cài Đặt Thư Viện:**
   ```bash
   flutter pub get
   ```

3. **Khởi Tạo Native Assets:**
   Cập nhật Icon và Splash Screen cho thiết bị:
   ```bash
   dart run flutter_launcher_icons
   dart run flutter_native_splash:create
   ```

4. **Khởi Tạo Models (Hive):**
   ```bash
   dart run build_runner build --delete-conflicting-outputs
   ```

5. **Vận Hành:**
   ```bash
   flutter run
   ```
